# Smarta Estate — Marketing Website

Marketing website for **Smarta Estate**, a smart water metering and billing platform for residential estates, complexes, and HOAs.

**A division of [Smarta](https://smarta.co.za/) — Simple. Smarter. Reliable.**

## Overview

Smarta Estate provides:
- 📊 **Smart Metering** — Automated IoT water meter readings
- 🏘️ **Property Management** — Estates, units, owners & tenants
- 💰 **Automated Billing** — Invoices based on actual consumption
- 🔔 **Alerts** — Leak detection, offline meters, high consumption
- 📈 **Analytics** — Consumption trends, benchmarking, reports

## Tech Stack

- Pure HTML, CSS, and vanilla JavaScript
- No frameworks or build tools required
- Hosted on GitHub Pages
- Google Fonts (Inter)
- Inline SVG icons (Lucide-style)

## File Structure

```
index.html          — Main single-page website
css/styles.css      — All styles (CSS custom properties, responsive)
js/main.js          — Interactions (scroll, menu, animations, form)
images/
  logo.svg          — Smarta Estate logo (droplet + building)
  favicon.svg       — Favicon (water droplet)
README.md           — This file
```

## Development

Just open `index.html` in a browser. No build step needed.

```bash
# Quick local server
python3 -m http.server 8000
# Then visit http://localhost:8000
```

## Deployment

This site is designed for GitHub Pages. Push to the `main` branch and enable Pages in repository settings.
